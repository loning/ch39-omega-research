## 第 39 章的阶段结论

2026 年 11 月 21 日，Lean FRO 与 Mathlib Initiative 联合确认了 Alpöge 的黎曼猜想形式化命题与证明。本仓库取具体正零点的高度包围区间做有限算术检验；物理作用与匹配条件在各节单列。[Lean 与 Mathlib 联合声明](https://leanprover-community.github.io/blog/posts/riemann-hypothesis/)

十九点贝伦德球壳的两个外层共有十五个点，一次坐标对换只固定其中一个。将壳反射与弱中心作奇投影给出系数 $t=1/15$。在指定的统一群面作用中，它固定三个裸逆耦合的比值为 $24/25:16/15:1$。给定能标和共同标定后，允许三个低端规范输入各浮动 $0.07\%$ 即能达到一组两圈高端目标。固定输入中心时，每个回路至少一支逆耦合仍相差 $0.0287$ 以上。[壳投影与输入范围](https://github.com/loning/ch39-omega-research/pull/29)

对未放大的正面权，从第一个实际零点起，完整四维格点测度中的有界局部场强相关已经指数衰减。这给出了高精度局部匹配与长程 Maxwell 动力学之间的定量障碍。把乘数放入微观作用会改变测度，在完整统一群上加三面圆盘便能测出大于 $0.09222$ 的刚度增量。[连通相关](https://github.com/loning/ch39-omega-research/pull/33) · [微观放大后的圆盘检验](https://github.com/loning/ch39-omega-research/pull/36)

在共轭不变的外部权下，两种有限阶转角的读数可区分前 3200 个实际零点。若只有独立的未放大边界样本，两种相邻候选都要求至少 95% 判对率时，样本数须超过 $10^{22}$。所有结论均附模型假设、书面论证与复算代码。统一能标与绝对标定的来源、长程规范动力学以及引力的定量闭合仍是开放问题。[有限读数](https://github.com/loning/ch39-omega-research/pull/37) · [样本下界](https://github.com/loning/ch39-omega-research/pull/39)

四维格点的各次常数通量共用有理欧氏度量 $g=I-J/5$。在这一度量上加入 Regge 作用，其长波二次项给出 Fierz–Pauli 动能。取逆格距等于选定的匹配能标、规范与引力共用微观系数，并输入书中的普朗克标尺时，相容的实际正零点恰为第 11485 至 11490 个。这是关于裸作用与给定输入的条件分类。[几何与引力归一](https://github.com/loning/ch39-omega-research/pull/44) · [高零点复算](replay/ch39-high-zero-planck-window.py)

在同一度量上，五步 Wilson 核在 $(25-5\sqrt5)/4<m<7/2$ 内恰有三个同定向自由 Weyl 物种。重叠核的统一谱隙等于 $m$ 到最近窗口端点的距离，在边长为三十的倍数时取到。三个物种的平移特征只容许交换共轭的一对，十九点壳上的三阶轮换需要额外的味结构。核与质量窗口的选择、相互作用下的手征测度和质量谱仍待解释。[自由物种复算](replay/ch39-simplex-overlap.py)

在三个轻物种上，允许独立的复五周期系数时，单步 Yukawa 顶点能实现任意投影味矩阵；若要求严格有限程的裸顶点同时解耦另外两个中心动量，两步恰好足够。上下部门只用同一点的同一复背景及其共轭，则质量比被锁定为逐代相同。两支独立复背景已有显式非零 CP 不变量。[味矩阵复算](replay/ch39-period-five-flavor.py)

对 $m=139/40$ 的五步核，显式带两面整数磁通的 $SU(5)$ 周期背景有大于 $1/100$ 的核谱隙。采用未放大的 RH 零点三角面权并独立积分负对角链时，任何正阈值在足够大的有限盒里都以任意给定高置信度被最小奇异值突破。显式概率界保留了面权引起的全部边关联。[磁通与小奇异值的复算](replay/ch39-plaquette-overlap-gap.py)

把费米子的负对角步强制设为四条坐标链的逆积，仍可用两个二维反射实现零模。在未放大的零点面权中，任意固定近零窗口的期望本征值数有正的、正比于可容纳小盒数的下界。对独立负对角链还得到整个厄米核可能能区的逐点覆盖。[闭合链与低谱计数](replay/ch39-closed-link-spectrum.py)

在 $5^4$ 周期盒的一组显式闭合 $SU(5)$ 链上，共轭基本与外平方的重叠指数分别为 $2,7$，中心在左手行列式线上的荷为 $-2+2\cdot7=2\pmod5$。该反例在零点面权的一个正概率开集上稳定，阻碍这个指定模型在全部粗糙背景上选取规范等变的 Weyl 测度。[手征指数反例](replay/ch39-rough-overlap-index.py)

即使对 $\bar{\mathbf5}$ 和 $\mathbf{10}$ 独立选择 Wilson 质量，三个显式背景也覆盖了整个三物种窗口的质量对。每一对质量都遇到一个具有正概率、中心在 Weyl 行列式线上作用非平凡的开集。[全窗口证书](replay/ch39-uniform-center-obstruction.py)
